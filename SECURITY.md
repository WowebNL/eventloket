# Security policy
Woweb will take all security bugs seriously. We appreciate your efforts to disclose the issue responsibly, and will make every effort to acknowledge your contributions. To help us with the vulnerability(s) you have identified, it would be great if you could please follow the reporting guidelines below to submit your finding.

Please do not report a vulnerability in a pull request, discussion or any other public channel.

## Reporting Guidelines

You can report a vulnerability confidentially in one of two ways:

- Through GitHub private vulnerability reporting: open the [Security tab](https://github.com/WowebNL/eventloket/security) of this repository and choose "Report a vulnerability". Only you and the maintainers can see the report.
- By email to security@woweb.nl.

Please include the following information:

1. Name / affiliation
2. Vulnerability description
3. Steps to reproduce the issue
4. Current public knowledge of this vulnerability (e.g. related CVE, security advisory, etc.)

## How reports are handled

Reports are handled confidentially, and details of a vulnerability are not made public before it has been resolved. Where applicable, a GitHub security advisory is published once a fix is available.
